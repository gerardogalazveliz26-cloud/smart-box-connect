# DJ Chany Panel

App Android para activar equipos de **DJ Chany IPTV** con su código `DJ-XXXXX-XXXXX`. Lleva dentro el panel de `../panel/index.html`.

- **Compartir desde WhatsApp:** mantén presionado el mensaje del cliente → Compartir → *DJ Chany Panel*. El código se completa solo y, si el equipo ya estaba activado, se cargan sus datos.
- **📋 Pegar:** toma el código copiado del portapapeles.
- Activar, editar y dar de baja equipos, ver «Mis clientes», guardar copias de seguridad y cambiar el servidor en todos los equipos.

El workflow `.github/workflows/djchany-panel.yml` compila el APK con la misma firma que DJ Chany IPTV y lo publica con el tag `djchany-panel-v<versión>`.
